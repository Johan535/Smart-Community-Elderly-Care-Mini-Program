## 项目结构

- `backend`：Java Spring Boot 后端（三层架构）
  - `controller`：接口层
  - `service`：业务层
  - `repository`：数据访问层（内存实现）
- `miniprogram`：微信小程序前端（老人/家属端 + 社区工作人员端）
  - `api`：接口调用模块（按老人端/工作人员端拆分）
  - `utils`：工具模块（请求签名、缓存、角色校验）

## 已实现功能

### 老人/家属端
- 个人与老人信息管理（新增/维护、照片上传、多老人切换）
- 健康监测管理（数据录入、记录查看、提醒字段录入）
- 生活服务申请（浏览申请、预约、订单状态、评价投诉入口）
- 紧急求助（一键求助、信息发送、记录留存）
- 活动与社交（活动查看、报名、互动发布）

### 社区工作人员端
- 老人信息管理（档案查看、风险标记）
- 服务管理（接单派单、状态更新、投诉信息查看入口）
- 活动管理（发布、报名人数管理、导出入口）
- 求助处理（实时接收、处理记录）
- 数据统计分析（服务/健康统计、日周月报生成入口）

## 阶段二代码质量优化

- 模块划分：前后端按角色、功能、工具、接口拆分，降低耦合，便于维护扩展。
- 编码规范：统一命名风格，核心安全与权限逻辑集中在拦截器和工具层。
- 性能优化：
  - 请求默认超时控制 3 秒内，GET 请求增加短时缓存降低重复请求。
  - 紧急求助接口独立超时策略（900ms）提升响应感知速度。
  - 后端内存数据结构改为并发容器，提升并发访问稳定性。
- 安全优化：
  - 老人隐私字段（姓名、病史、过敏史、紧急联系人、照片地址）加密存储。
  - 后端新增严格角色权限拦截（老人/工作人员权限隔离）。
  - 前后端增加请求签名校验与时间窗校验，防止请求被篡改和重放。

## 阶段三界面优化（适老化）

- 界面简洁化：统一卡片布局，减少干扰元素。
- 字体和按钮放大：提升老年用户阅读与点击体验。
- 双端区分：老人端绿色主题，工作人员端蓝色主题。
- 引导提示：每页加入简短操作说明，降低学习门槛。

## 阶段四创新点（轻量实用）

- 创新点1：老人端一键大字模式
  - 在老人信息页可一键开启/关闭大字模式。
  - 模式状态本地持久化，老人端相关页面自动同步。
- 创新点2：健康异常自动预警 + 简易风险评估
  - 健康录入时自动识别血压/血糖/心率异常并即时提示。
  - 基于历史异常占比给出低/中/高风险等级与建议。
