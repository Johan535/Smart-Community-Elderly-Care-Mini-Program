# 社区智慧养老服务微信小程序 - 使用说明文档

## 1. 运行环境

- 操作系统：Windows
- 后端：JDK 17、Maven
- 前端：微信开发者工具

## 2. 启动步骤

### 2.1 启动后端

```powershell
cd d:\虚拟c盘\Java赛道KFZSF260141王俊翰\backend
mvn spring-boot:run
```

- 后端接口地址：`http://127.0.0.1:8126/api`

### 2.2 启动小程序

1. 打开微信开发者工具。
2. 导入项目目录：`d:\虚拟c盘\Java赛道KFZSF260141王俊翰\miniprogram`。
3. 调试阶段允许本地请求。
4. 进入首页后选择角色。

## 3. 双端操作指南

### 3.1 老人/家属端

1. 首页选择“老人/家属端”。
2. 在“个人与老人信息管理”页面填写并保存信息。
3. 可进入“多老人切换”设置当前管理老人。
4. 在“健康监测管理”录入健康数据，查看预警和风险评估。
5. 在“生活服务申请”提交预约并查看订单状态。
6. 在“紧急求助”页面一键发起求助并查看记录。
7. 在“活动与社交”查看活动、报名、发布互动。

### 3.2 社区工作人员端

1. 首页选择“社区工作人员端”。
2. 在“老人信息管理”查看档案并进行风险标记。
3. 在“服务管理”处理派单与状态更新。
4. 在“活动管理”发布活动并管理报名数据。
5. 在“求助处理”处理紧急求助并记录结果。
6. 在“数据统计分析”查看指标并生成报表入口。

## 4. 主要功能使用步骤（快速演示版）

- 演示步骤建议：
  1. 先在老人端新增老人信息并切换。
  2. 录入一条正常健康数据，再录入一条异常数据，展示预警与风险评估变化。
  3. 提交一条服务预约，并切换工作人员端进行派单处理。
  4. 发起一条紧急求助，再切换工作人员端进行处理留痕。
  5. 查看统计页，演示数据汇总结果。

- 项目为竞赛基础可运行版本，重点满足题目完整性与可展示性。
